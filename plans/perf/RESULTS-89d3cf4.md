## Review of decisions 01 and 02

Three classes of output difference, repros in `plans/perf/repros-89d3cf4/` (`bash plans/perf/repros-89d3cf4/run.sh` prints one DIFF per call):

1. `newt-convention`: `constructed_types` counts `func NewLazy()` as constructing `Lazy`, but that file never holds the word `Lazy`, so `constructed()`'s `ask(ty)` never loads it. Interface dispatch then drops `Lazy.Run`. Differs on callers, callees, explain, `path -->` and `path ==>`.
2. `named-result-line`: in path data flow, a type constructed only by a function whose named results sit on their own lines (`l *Lazy,`) is missed, since `declare_at` has no rule for that position. Interface widening drops the method.
3. `semicolon-decl`: `var x = 1; func OneLine(...)` and `type T struct{}; func (T) Run(...)` on one line are missed by `name_at`/`declare_at` in path data flow. Not gofmt style.

Held, byte for byte: needles (names only in comments or strings, unicode, case, regex escapes and flags, `--tests` on and off, `:not`, `.body`, `.params`, `~` and `+` with one side missing, glossary, `method`/`const`, qualified names, `--exclude`, `--max-matches`, `-C`, `--scope`), `find` key prefilter (case, Next.js path keys, Rails key rewrite, error keys), scoped graph on Go/Rust/JS/Ruby fixtures (1,336 generated callers/callees/explain/def/refs calls at depth 1, 3 and 6) plus 146 calls on 45 random Mavexa functions, path on a Go flow fixture (1,152 routes).

The reference cache: editing a file under the root, same size, invalidates the entry. Gaps, all low: the environment passed to `run_ref` is not in the key; files outside the root (parent `.gitignore`, a repo `.ctsq/` above a fixture root, `~/.config/ctsq`) are not fingerprinted; the fingerprint is memoised per process.
